2. 用54行语义表定位原生ID。梯子必须读取Foot/Top，不把根节点0,0当位置；另11根梯子见15行端点表。保持原生ID，禁止手猜坐标。
3. D兽出生(150,-4)、S02主录(146,-4)、右喇叭(177,-4)、补录(182,-4)。距离分别为4、27、5（补录对引右目标）；需验证28声程、真实发声点、遮挡、采音安全、引右停留和回位。D桥梯在兽右侧仍不能证明无法跳兽绕行。
4. D—E三梯X198.7/197.3/199.7；两中台X198..210、189..199；E顶岩X157..189。主实施已补D—E侧壁并修正缩放后的MossLip位置；当前几何修正不替代整段身体净空测试。F左警报头部空间、低挡块与地波判定须单独联调。
5. 最后接完整流程、出入室、存档恢复和经济幂等，再做人工通关。

## UI接入

唯一Prefab：`Assets/_EchoCaves/UI/Prefabs/EchoCavesUI-v03.prefab`。场景已有UI根，不再叠实例。源码打磨后场景根及Prefab均已原生重建，主实施报告13视图161标签契约PASS。13视图为HUD、MainMenu、Pause、Settings、Dialogue、Map、SoundLibrary、Playback、Radio、Shop、Settlement、Fail、End。

EchoUIBindings.Views及ShowView/OpenSettings/BackFromSettings管理展示和返回；业务UnityEvents、数值、存档及音量持久化由B接。默认隐藏Boss失衡示例、录音/反馈快照及审阅导航；F1仅切换审阅dock。白色三格为失衡，不是Boss血条。SceneReview方向键移动相机、左Shift加速、PageUp/Down切12书签，绝非玩家控制器。

真实Play中Input System队列Enter进入Settings且恰好1个EventSystem通过，为自动化烟雾测试；不证明所有界面与业务操作通过。
