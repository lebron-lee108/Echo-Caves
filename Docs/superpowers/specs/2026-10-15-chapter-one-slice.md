# VP515 第一章可玩切片规格

用户要求先做出实际可玩版本再判断画风，不继续以文字选择和逐段确认阻塞制作。此规格记录本轮自主取舍；样片和新增机制均需实际试玩，不作为团队已经验收的最终章规则。

## 目标与范围

在现有 Unity 6000.3.23f1 Universal 2D 工程中建立可继续扩展的首节。约三屏宽的枯木森林、一个双形态谜题、一种敌人、一个回复道具和一个出口。目标初次体验约两到三分钟，时长须真实试玩。完整菜单、游戏 HUD、背包、暂停、设置、死亡恢复与结束重玩同时交付。不加入商店、锻造、技能树、Boss、多人、账号或 LLM。

## 视觉与参考

非像素、简化手绘。冷灰枯木、暖金雾光、深色近景、青蓝蝴蝶；角色/地形清楚，远景少细节。参考图片与57.17秒视频仅作为分析来源，不复制其原素材。AI生成资产必须标注，保留项目内可替换源文件。背景三到四层视差，前景只遮画面边缘，不挡可行走路线、机关或小怪预警。

用户夜间更新：允许借图片地图构图与地形，允许图片与视频美术融合；不是必须一比一使用某一种画法。缩小的是内容量，不降低动作、战斗、UI、镜头、声音与整体成熟度要求。以视频质量作为达到并超越的目标，但实际是否达到须通过动态呈现和试玩，不能由自动测试宣布。尤其重视镜头随人物运动时的远近景视差，以及飘落叶片、微尘等环境运动；枯木森林先用金色落叶而非改成樱花主题。参考衍生素材本地候选不等于已取得公开分发授权。

## 首节路线

入口安全地面教授 A/D 或方向键移动、Space 跳跃、J 或鼠标左键攻击。安全起点有检查点灯和一枚回复露珠。

中段机关：人形 E 检查提示，Q 脱壳，身体留在压力台上；蝴蝶用 WASD/方向键飞行，穿过人形不能通过的窄口，以 E 激活青蓝符印。符印锁存开启主路门；Q 返回身体；人形沿主路继续。蝴蝶持续飞行受能量限制，能量耗尽自动返回；身体/蝴蝶掉出安全边界恢复到检查点，不能卡死。机关解锁在死亡时保留，重新开始整节时清空。

后段一只枯木小怪：巡逻、发现、攻击预警、冲撞、恢复、受击、死亡。玩家近战有挥击轨迹、一次攻击只伤同一敌人一次、命中停顿和轻微可关闭震动。玩家100生命，敌人三次有效近战击败；伤害后短暂无敌，不能一帧持续扣血。蝴蝶不能攻击敌人，UI提示回到身体战斗。

小怪被击败后出口灯可激活；E结束本节，显示用时、击败和拾取记录，可重新开始或回主菜单。

## UI 与输入

uGUI + TextMeshPro；1920x1080参考，响应式缩放。英文运行文案与简洁图形，中文操作说明存 Docs。开始菜单含 Start Journey、Controls、Settings、Quit；进入游戏有淡入与章节短提示。HUD含生命、蝴蝶能量、当前目标、背包道具、上下文交互提示。Tab背包中可使用回复露珠，Esc暂停。暂停/背包/设置阻止角色移动、攻击和敌人更新；结束或死亡不能继续受伤。设置含总音量、震动开关并本地保存。不在背包关闭后把同一鼠标点击透传成攻击。

主菜单使用同一真实游戏世界的静止构图，不以概念图冒充实机。控件 hover/选中/按下都有反馈，键盘可导航；首次进入有可读操作说明，HUD不能挡路。无数据、不可用道具有解释，不做看似可用却没有行为的按钮。

## 实现边界

保留 Foundation 和 SampleScene。新场景 Assets/_VP515/Scenes/ChapterOneSlice.unity；所有新文件在 feature/chapter-one-slice，未经验收不合并 main。场景和序列化资产由 Unity API 创建，不能手写 YAML。运行代码按纯规则、角色、敌人、关卡交互、表现、UI分离。关卡地形与资产模块能扩展，不复制整幅参考图。

## 验收

规则自动测试包含生命与无敌、回复道具消费、能量与自动返回、符印解锁与重启、攻击去重及暂停阻止推进。实际Unity编译无错误。实机输入路径验证 Start → 行走/跳跃 → 机关 → 回身体 → 攻击 → 出口 → 重玩；另验证失败、暂停、背包和音量。至少检查1280x720及1920x1080菜单/HUD，输出截图与Windows构建。自动合成输入与作者自测不冒充真人新手测试、团队画风验收或课程高分保证。
