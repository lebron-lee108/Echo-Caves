# VP515 第一小节试玩说明

当前为本地可玩审阅候选，继续优化后作为完整游戏的起点；不是独立于VP515的一次性演示。美术与主观手感尚未由用户验收。

## 打开

首轮审阅包位于 `E:/VP515/Builds/Windows/ChapterOneSlice-v04/`，双击 `VP515.exe`。不要只拷走EXE，旁边Data目录与DLL必须一起保留。也可以Unity中打开 `Assets/_VP515/Scenes/ChapterOneSlice.unity`，按Play，点Start Journey。不要打开旧Foundation或Sandboxes内的备份。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | A/D或左右方向键 |
| 跳跃 | Space |
| 近战 | J或鼠标左键 |
| 蝴蝶脱壳／回身体 | Q |
| 蝴蝶飞行 | WASD或方向键 |
| 拾取、休息、激活、出口 | E |
| 背包 | Tab |
| 暂停／返回 | Esc |

菜单支持鼠标，也支持方向键选择、Enter确认。Settings中音量和镜头震动会本地保存；关闭震动不影响操作。

## 通关路线

入口附近有检查点灯和青蓝露珠，靠近按E拾取；受伤后Tab打开背包，Use Dew回复35生命，满血时不会浪费。沿桥向右，Space越过小岩石。

走到发光压力台上，身体站稳后按Q。身体留在台上，蝴蝶飞向门上方的窄口；飞过后靠近高处青蓝符印，按E。符印亮起后门开启，按Q返回原身体，再往右走。

蝴蝶消耗能量，耗尽自动返回；不能用蝴蝶近战。遇到枯木怪时观察红色预警，躲开冲撞，在空档靠近按J。三个有效命中击败怪物；一次挥击不能重复扣多次敌人生命。

走到右侧出口灯，靠近按E进入结束页，可Play Again或回菜单。死亡时Return to Checkpoint保留已经打开的门；Restart Section或Play Again清空整节进度。

## 反馈重点

先看实际运动：背景各层移动、落叶、角色脚底与步态、跳跃、蝴蝶机关和近战。反馈可以只描述感受，例如“背景太平”“动作太慢”“打中没力度”“菜单像工具”，不需要先给专业术语。画面、动态、声音和可用性分别反馈，不以自动测试通过代替认可。
